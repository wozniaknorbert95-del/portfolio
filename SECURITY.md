# Security Policy

## Scope

This repository is a public proof candidate under review. Do not publish credentials,
tenant data, client records, internal hosts, local paths or operational screenshots.

## Reporting

Report suspected vulnerabilities privately to `quietforge@flexgrafik.nl` with the
affected file or URL, reproduction steps and impact.

## Status

The repository is not approved as a production deployment or open-source product.
Public visibility does not grant a licence or permission to reuse QuietForge framework,
tenant code or client data.
